# 財布 SAIFU

今月あといくら使えるかが一目で分かる、ひとり用の金銭管理アプリ。
https://sho3690.github.io/saifu/

- 記録: 金額とメモを入れるだけ。メモの言葉から分類を自動で選び、選び直した結果を覚えます。
- 今月: 残額、「あと◯日、1日◯円まで」の案内、使うペースの図、分類ごとの内訳。
- 履歴: 月ごと・日ごとの一覧。押すと直せます。絞り込みつき。
- 設定: 月の予算、固定費（毎月自動で計上）、控えの書き出し（JSON / CSV）と読み込み。

## データの置き場所
記録はブラウザの localStorage（このリポジトリの外、端末の中だけ）に保存されます。通信もアカウントもありません。
機種変更の前に「設定 → 控えを書き出す」で JSON を保存してください。

## 開発
ビルド不要。`python3 -m http.server 8793 --bind 127.0.0.1` などで開きます。
計算部分（logic.js）は `npm test`（node --test）で検証します。
